# 배우자 증여 절세 계산기 · 똑재TV

오른 해외주식을 배우자에게 증여한 뒤 배우자가 팔 때, 내가 그대로 팔 때와 증여세·양도세를 비교하는 계산기. 증여 후 1년 안에 팔 때의 이월과세와, 증여한 주식의 배당을 배우자 금융소득으로 나눌 때 종합과세 기준(연 2,000만원)도 보여 준다.

- 사이트: https://ttokjaetv.github.io/spouse-gift/
- 근거(2026-10-24 국가법령정보센터 원문 확인)
  - 소득세법(2026-01-01 시행본): 제97조의2 이월과세(주식등 1년, 2024.12.31 개정 부칙 제8조 — 2025-01-01 이후 증여받는 자산부터, ②3호 적용 배제), 제101조② 부당행위계산(배우자·직계존비속 제외), 시행령 제163조⑨ 증여받은 자산 취득가액 = 상증법 평가액, 시행령 제163조의2② 증여세 상당액
  - 상속세 및 증여세법: 제47조② 10년 합산, 제53조 배우자 공제 6억, 제55조② 과세최저한, 제56조 세율, 제58조, 제69조② 신고세액공제 3%
- 증여 평가액은 직접 입력. 해외 상장 주식은 실무 안내(개별 주식 = 증여일 전후 2개월 종가 평균 × 증여일 환율, ETF = 증여일 무렵 종가)를 화면에 안내하되 국세청·기재부 공식 해석은 미확인으로 표시.
- 제도 숫자는 허브 `rules/v2026.3/rules.js`의 `GIFT`·`OVERSEAS_STOCK`·`FIN_INCOME`에서 읽는다. 이월과세 기간(주식 1년)은 rules에 없어 화면 문구로만 쓴다(계산은 '1년 안/지나' 선택).
- 넣지 않은 것: 수수료·환전 비용, 외국납부세액공제, 실질과세(판 돈을 증여자가 가져가는 경우), 상속 시 사전증여 가산, 국내시장 복귀계좌(RIA) 공제.

## 수정하는 법
`src/`를 고친 뒤 `python src/build.py` → `index.html`. 시험 `node src/test.js`(기대값은 법령 손계산).
